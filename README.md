# 📊 Desafio: Filtro de Vendas com Menu Interativo

Este foi o meu primeiro projeto prático desenvolvido em **Python**! O objetivo principal foi consolidar os conceitos básicos da linguagem, fazendo a transição da lógica estruturada que utilizo em C na faculdade para a sintaxe dinâmica do Python.

---

##  O que o programa faz?

1. **Menu de Estoque Visual:** Exibe para o usuário uma lista organizada de produtos disponíveis no escritório e seus respectivos preços.
2. **Entrada de Dados:** Solicita que o usuário digite o nome do produto e o preço (utilizando conversão para `float`).
3. **Classificação Automática (Regra de Negócio):** * Se o valor for **maior ou igual a R$ 1000,00**, o produto é classificado como **Categoria Premium**.
   * Se o valor for **menor que R$ 1000,00**, o produto é classificado como **Categoria Padrão**.

---

##  Conceitos de Python Praticados

* **Saída de dados:** Uso do `print()` com quebras de linha (`\n`) para estilizar o terminal.
* **Entrada de dados:** Uso do `input()` para capturar dados do usuário (equivalente ao `scanf` do C).
* **Tipagem Dinâmica e Conversão:** Uso de `float()` para converter o texto digitado em um número decimal.
* **Estruturas Condicionais:** Aplicação de `if` e `else` utilizando a indentação correta do Python (sem a necessidade de chaves `{}` ou ponto e vírgula `;`).
